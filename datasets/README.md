# SkillBridge Datasets Information & Data Dictionary

This directory contains the core training and operational datasets for **SkillBridge**:
1. `students.csv` - Student academic profiles.
2. `student_skills.csv` - Student technical & soft skills with proficiency levels (1-5).
3. `job_roles.csv` - Standardized industry job roles & career tracks.
4. `job_requirements.csv` - Specific technical skill demands & expected proficiency per job role.
5. `internship_data.csv` - Internship opportunities, eligibility, and skill criteria.
6. `learning_resources.csv` - Verified courses, tutorials, and documentation links.
7. `career_labels.csv` - Feature-engineered career categories for the Random Forest classifier.

A Python dataset generator script will synthesize clean, realistic data strictly reflecting CSE/IT curricula and current industry hiring standards (SDG 4 & SDG 8).
